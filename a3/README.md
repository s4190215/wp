Project Description
PetConnect is a dynamic web application for pet adoption.
It is developed using PHP, MySQL, HTML, CSS, JavaScript, and Bootstrap 5.

The application allows users to browse pets, view detailed information, and add new pets for adoption with image uploads.

Features
Dynamic content using PHP and MySQL
Home page displaying recently added pets
Browse pets page with search functionality
Pet details page with full information
Add pet form with validation and image upload
Gallery with filtering and modal view
Secure database queries using prepared statements
Image upload with unique filenames
Responsive design using Bootstrap 5
